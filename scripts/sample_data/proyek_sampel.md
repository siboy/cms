# Proyek sampel untuk uji engine CMS

Dipetakan dari grup WA kerja (akun 2020, backup `waindex/wa.sqlite`), bukan data fiktif.
Tim inti (lintas 3 proyek) ada di `tim_amdal.csv` — impor dengan:
`python scripts/cms_admin.py users-csv scripts/sample_data/tim_amdal.csv`

Lalu assign ke bab dokumen sampel (per proyek jadi 1 dokumen uji) dengan:
`python scripts/cms_admin.py assign <doc_id> <username> <scope>`
