Instal aplikasi sdrive di Android

Aplikasi ini dibagikan langsung sebagai file APK (bukan lewat Play Store), jadi Android akan menampilkan satu peringatan keamanan standar saat instalasi pertama. Ini normal — ikuti 3 langkah di bawah, dan ini hanya perlu dilakukan sekali saja per HP.

⬇ Unduh sdrive.apk

1 Buka file APK yang sudah diunduh

Setelah unduhan selesai, ketuk notifikasi unduhan (atau buka lewat aplikasi Files/Berkas). Android akan menampilkan layar "Untuk keamanan ponsel Anda..." — ini wajar untuk APK di luar Play Store.

2 Izinkan "sumber tidak dikenal" untuk aplikasi pengunduh

Ketuk Pengaturan pada layar peringatan tadi, lalu aktifkan sakelar "Izinkan dari sumber ini" (nama persisnya beda-beda tergantung merek HP: "Install unknown apps", "Sumber tak dikenal", dll).

Izinkan dari sumber ini

3 Kembali dan ketuk Instal

Tekan tombol kembali, lalu akan muncul lagi layar instalasi aplikasi sdrive — ketuk Instal. Selesai. Pembaruan aplikasi berikutnya tidak akan menampilkan peringatan ini lagi.

Instal sdrive?
Kenapa harus begini? Google membatasi instalasi aplikasi di luar Play Store demi keamanan. Aplikasi sdrive dipakai internal oleh perusahaan Anda — bukan aplikasi publik, jadi tidak didaftarkan ke Play Store. Peringatan yang muncul bukan berarti aplikasi berbahaya, hanya langkah verifikasi standar Android.
Setelah terinstal, buka aplikasi dan masukkan kode perusahaan Anda untuk masuk.
